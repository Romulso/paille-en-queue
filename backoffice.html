Le Paille en Queuebackoffice

Le backoffice n'est pas encore raccordé à Supabase.

Deux valeurs à coller dans le code de cette page, tout en bas, dans le bloc RÉGLAGES :

  1. Ouvrir le projet sur supabase.com, menu Project Settings → API.
  2. Copier Project URL dans SUPABASE_URL.
  3. Copier la clé anon / public dans SUPABASE_ANON.
Ces deux valeurs sont publiques et peuvent figurer dans le dépôt : sans compte, elles ne donnent accès à rien, car chaque table est fermée par RLS. La clé service_role, elle, ne doit jamais apparaître ici — elle contourne RLS et ouvrirait la base à tout le monde.
